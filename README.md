#Python Merging Techniques
#Project Overview
This project demonstrates basic data merging techniques in Python using the pandas library.
It shows how different datasets can be combined to create a unified dataset for analysis.

#Objectives
Understand how to merge datasets in Python
Practice using pandas for data manipulation
Learn different types of joins used in data analysis

Skills Used
  Python
  pandas
  Jupyter Lab

#Concepts Demonstrated
Inner Join – returns matching records from both datasets
Left Join – returns all records from the left dataset and matching records from the right
Right Join – returns all records from the right dataset and matching records from the left
Outer Join – returns all records from both datasets

#Learning Outcome
Combine datasets using pandas
Choose the correct join type for different analysis scenarios
Prepare datasets for further data analysis or machine learning tasks
